# Quiz-Anwendung

Dieses Projekt ist eine Quiz-Anwendung, die im Rahmen des Kurses „Webbasierte Anwendungen“ an der Hochschule RheinMain entwickelt wurde. Die Aufgabe war als Gruppenarbeit für zwei Personen konzipiert, und ich habe sie gemeinsam mit einer Kommilitonin umgesetzt.

## Technologien

Dieses Projekt verwendet:
- **Java**
- **Spring Boot**
- **Gradle**
- **Vue.js**
- **HTML**
- **CSS**
- **TypeScript**
- **JavaScript**
- **Python**
